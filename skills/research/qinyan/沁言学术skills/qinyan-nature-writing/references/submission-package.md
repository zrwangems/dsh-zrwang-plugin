# 首次投稿材料

## 交付矩阵

根据目标期刊的当前 author instructions 核对，而不是假设所有 Nature Portfolio 期刊要求相同。

| 材料 | 核心内容 | 必须由作者确认 |
|---|---|---|
| Cover letter | 研究问题、核心进展、广泛意义、期刊适配、独家投稿声明 | 通讯作者、相关稿件、预印本、编辑沟通 |
| Title page | 标题、作者、单位、通讯信息 | 姓名拼写、顺序、单位、邮箱 |
| Author contributions | 按目标期刊或 CRediT 角色表述 | 每位作者角色与同意 |
| Competing interests | 利益冲突声明 | 全体作者确认 |
| Data/code availability | 数据、代码、访问条件与持久标识 | 仓库状态、访问限制 |
| Ethics statements | 审批、同意、注册信息 | 编号与适用性 |
| Suggested reviewers | 专业匹配与无冲突说明 | 利益冲突、近期合作 |
| Excluded reviewers | 简洁、专业的回避理由 | 必要性与事实 |

## Cover letter 结构

1. 指明稿件标题和文章类型。
2. 用一段说明问题、主要进展和最有力证据。
3. 说明跨领域或目标读者价值，不重复摘要。
4. 陈述相关稿件、预印本、数据/代码状态和投稿合规信息。
5. 以作者身份信息与联系方式收束。

避免：

- 预测编辑决定；
- 以期刊影响因子作为投稿理由；
- 列出所有结果；
- 使用无法验证的优先权或轰动性语言；
- 虚构审稿人信息。

## 就绪状态

- `ready`：信息齐全且已核验；
- `ready_with_author_checks`：正文可用，但仍有明确作者确认项；
- `blocked`：缺少作者、伦理、利益冲突、数据访问或其他关键事实。
