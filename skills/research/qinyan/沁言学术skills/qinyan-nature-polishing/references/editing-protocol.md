## 1. Fidelity ledger

润色前记录：

| 类别 | 必须保持 |
|---|---|
| 数值 | 数值、单位、误差、p 值、区间 |
| 方向 | 增加/降低、优于/劣于、正/负相关 |
| 实体 | 组别、物种、材料、数据集、模型 |
| 条件 | 时间、剂量、环境、纳排条件 |
| 证据层级 | 观察、关联、预测、干预、机制 |
| 引用意图 | 哪一来源支持哪一陈述 |

改写后逐项比对，不仅依赖整体阅读感。

## 2. 四层编辑

### 层 1：科学含义

修复或标记：

- 主张超出结果；
- 比较对象不清；
- 条件或限定语缺失；
- 观察与解释混合；
- 前后数值或方向冲突。

### 层 2：段落逻辑

检查：

- 第一信息是否定义段落任务；
- 每句是否推动同一任务；
- 证据是否紧邻相应声称；
- 末句是否合理收束或转接。

### 层 3：句子

优先使用清晰主语与具体动词。拆分承载多个逻辑动作的长句，合并重复的短句。保留领域真正需要的被动语态。

### 层 4：表面规范

统一拼写、大小写、连字符、缩写、符号、单位、标点和引用格式。

## 3. 声称与动词

| 证据 | 可优先考虑 | 谨慎或避免 |
|---|---|---|
| 描述性观察 | observed, showed, was higher | caused, drove |
| 关联分析 | was associated with, correlated with | determined, mediated |
| 预测模型 | predicted, discriminated, estimated | explained the mechanism |
| 干预实验 | increased, reduced, altered | was sufficient/necessary（除非设计支持） |
| 机制证据 | mediated, depended on | universal claims |

使用 `may`, `might`, `suggest`, `consistent with` 时说明不确定性来源，避免无意义地每句降调。

## 4. 中译英

不要逐词映射中文语序。先提取：

1. 谁或什么执行动作；
2. 发生了什么；
3. 在什么条件下；
4. 证据是什么；
5. 结论可到哪里。

常见修复：

- 删除“众所周知”“具有重要意义”等无证据元话语；
- 把连串“通过……从而……”拆成可验证动作；
- 避免每句都用 `This study` 或 `It is worth noting that`；
- 使时间、条件和比较对象靠近其修饰成分；
- 先写科学关系，再选择自然英文。

## 5. 去模板化

重点审查：

- 过密的 `Moreover/Furthermore/Additionally`；
- `delve into`, `pave the way`, `shed light on`, `paradigm shift` 等宣传或套话；
- 连续三句相同句式；
- 不必要的三项并列；
- 反复使用 `novel`, `robust`, `comprehensive`, `remarkable`；
- 用复杂名词短语隐藏简单动作。

目标是具体、克制、有节奏，不是追求罕见词汇。

## 6. 最终核验

- 数值和单位逐项一致；
- `not`, `only`, `respectively` 的作用范围正确；
- 比较级有明确基准；
- 代词有唯一指代；
- 缩写首次定义；
- 统计术语使用准确；
- 改写没有引入新事实；
- 作者声音仍可辨认。
