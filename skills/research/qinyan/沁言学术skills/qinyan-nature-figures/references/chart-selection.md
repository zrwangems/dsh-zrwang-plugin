# 科学问题到图形的选择

| 科学问题 | 首选图形 | 重点风险 |
|---|---|---|
| 两组或多组分布 | 点图、箱线/小提琴叠加原始点 | 隐藏样本量、伪重复 |
| 配对前后变化 | 配对点线图、斜率图 | 丢失配对关系 |
| 连续变量关联 | 散点 + 区间/模型 | 相关冒充因果、过度平滑 |
| 时间过程 | 个体轨迹、均值与区间、分面 | 把重复测量当独立样本 |
| 组成比例 | 堆叠条、点图、组成模型结果 | 闭合约束、百分比掩盖绝对量 |
| 高维矩阵 | 热图 + 清楚的尺度/聚类说明 | 彩虹色、聚类不可复现 |
| 分类性能 | ROC/PR + 区间、校准图 | 类别不平衡、测试集泄漏 |
| 效应与不确定性 | forest plot | 只展示 p 值 |
| 流程或方法 | 简洁流程图 | 视觉装饰替代技术信息 |
| 机制关系 | 分层示意图 | 把推测画成已证实路径 |
| 空间或显微图像 | 图像板 + 比例尺 + 定量面板 | 选择性视野、对比度处理 |

## 选择原则

1. 先识别独立实验单位和变量类型。
2. 再确定读者需要比较分布、趋势、关联、效应还是结构。
3. 优先保留个体层信息与不确定性。
4. 只有当聚合是科学问题的一部分时才只展示汇总。
5. 避免双 y 轴、3D 柱状图、面积误导、无必要雷达图和不连续色阶。

## 多面板组合

- 从问题或概念图进入；
- 用主证据建立结论；
- 用对照和机制解释可信度；
- 以稳健性或边界收束；
- 保持共享坐标、颜色和排序一致。

面板阅读顺序应在灰度打印和缩小后仍清楚。
