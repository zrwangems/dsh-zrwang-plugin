# 视觉、导出与图注标准

## 视觉层级

- 让主证据拥有最大视觉权重。
- 使用留白、对齐和共享轴组织关系，不用装饰性边框。
- 标题通常留给图注；面板内部只保留理解数据所需文字。
- 对照组、处理组和关键状态在所有面板保持相同颜色语义。

## 字体与线条

- 使用出版安全且可嵌入的字体。
- 在最终尺寸检查文字，而非仅依赖绘图画布字号。
- 保持坐标轴、误差线、数据线和注释线的视觉层级。
- 避免过粗坐标轴、过密刻度和不必要网格。

## 颜色

- 默认使用感知均匀、色盲友好的调色板。
- 不用 `jet`、`rainbow` 等非均匀色图表达连续量。
- 使用形状、线型或直接标签提供冗余编码。
- 发散色图必须有科学上有意义的中点。
- 类别过多时优先分面或直接标签，不无限增加颜色。

## 矢量与栅格

- 线图、散点、文本和示意图优先 SVG/PDF。
- 照片、显微图和高密度栅格按最终尺寸导出 TIFF/PNG。
- 通常把 300 dpi 视为彩色/灰度图的最低检查线，把更高分辨率用于线稿或期刊明确要求；最终服从目标期刊规范。
- 保留 SVG 文本和 PDF 字体，不无故转曲或栅格化。

## 图注

图注应独立回答：

- 每个面板展示什么；
- 样本与 `n` 如何定义；
- 数据如何汇总；
- 误差条、箱体、阴影与点代表什么；
- 使用何种检验/模型与多重比较；
- 符号、颜色和缩写含义；
- source data 或补充信息位置。

## 最终视觉 QA

1. 按目标宽度渲染。
2. 同时检查彩色、灰度和色盲模拟。
3. 放大检查矢量文字与栅格伪影。
4. 缩小检查面板顺序和主结论。
5. 检查图注、正文和图内标记一致。
6. 打开每种交付格式，避免“代码运行成功但文件损坏”。
